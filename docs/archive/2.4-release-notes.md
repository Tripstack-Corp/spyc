# spyc 2.4 — release notes

## The short version

2.4 is about the mouse and menus. Everything spyc draws now has a menu
showing what it can do, with each row's key beside it, so you can learn the
keys as you click. Agents got better at telling you what they need, and the
HUD now says what each Claude tab is doing and which account it's using.
About 35 features and 35 fixes.

## Heads-up

**Right-click opens a menu.** Right-click a file, a tab, the pane or a part
of the status bar to get a menu of what it can do, with each row's key
beside it. In Ghostty and Terminal.app a plain right-click on a file row now
opens that row's menu instead of the leader; right-click blank space for the
leader. In iTerm2, hold ⌃ as you right-click.

**Claude's vim-mode `Esc` is guarded.** With Claude Code's `/vim` on, a reflex
`Esc` in NORMAL mode interrupts a working turn. spyc now drops that `Esc` and
says so; `Shift-Esc` (on a terminal that reports it) or `^a Esc` interrupts
on purpose. (#956)

## What's new

### Menus

- `.` on a file row, `^a .` in the pane, or a right-click opens a menu for
  what's under it: a file, a tab, the pane or split divider, an open pager,
  and the status bar's projects, git, agent, session and background tasks.
  (#893, #943, #951, #962, #995)
- Each row names its key, and a clicked row's hint goes in front of what the
  action says. Once you've used the key yourself three times, its hint fades.
  (#898, #936, #940)
- Inside a mounted archive, the menu offers write back, discard and unmount.
  The session's menu renames it. (#1048, #1050)
- `Space m` lists the Makefile's targets, without running make to find them.
  Type to filter, and the target you pick runs as a capture. (#958, #960,
  #1024)

### The mouse

- Click a which-key row to do what its key does, or click beside the menu to
  close it. (#883, #885)
- Double-click a file to open it in the pager, or a directory to go into it.
  (#1080)
- Click a folder in the status bar's path to go up to it. (#1086)
- Click beside the centred pager to close it. (#1083)
- Click `y` or `n` to answer a confirm. A question that wants `y` or `n`
  pulses the screen's border if you click or type something else, so you
  notice it. (#998, #1084)

### Agents

- A blocked agent's notification says what it's waiting on: "claude needs
  you: Bash", or "codex needs you: command". Turn on `[notify]
  blocked_detail` and it also says what the tool acts on: "Bash · Run the
  test suite". (#973, #1061, #1063)
- A Claude turn that ends on an API error shows `blocked` and says why.
  (#945)
- When you come back to a tab that finished while you were elsewhere, the
  status bar recaps what it did: "1 turn · 3 tools (Edit 2, Bash 1) · done
  4m ago". (#1075)
- With `:agent hud` on, a Claude tab's strip names the subagents it's running
  and the tool each is using right now, "Explore · Grep". A dim rule sets the
  strip apart from the agent above it. (#952, #1068)
- The strip also shows the organization a Claude tab is logged into. If the
  tab sends requests with something other than that login, such as an API
  key, Bedrock or Vertex, the strip says that instead. (#1091, #1094)

### Smaller additions

- `gm` and `:diff` show a branch's changes since it left `main`, committed
  or not. Agents can do the same through `git_diff`'s `base`. (#1042, #1044)
- `yd` yanks the column's directory path. `]p` and `[p` jump to the next or
  previous pick. (#875, #1040)
- `:exec` runs the file under the cursor. (#887)
- `Esc Space` in the `:` prompt opens the `:` history. (#873)
- `spyc --cwd-file <path>` writes the directory you were in when you quit, so
  your shell can `cd` there. (#877)
- spyc's own stderr no longer draws over the screen. It goes to a log that
  `:stderr` opens, and a `⚠N` on the status bar counts what's new. (#879)

## Fixed: the greatest hits

About 35 fixes in all; `CHANGELOG.md` has every one. These are the ones you'd
have noticed.

- `^w` reaches the pane's program again. (#975)
- A restored shell tab reopens in the directory its shell was in, not where
  it started. (#948)
- Each Claude tab is read from the Claude Code home it runs with, so tabs
  started with different `CLAUDE_CONFIG_DIR`s each show their own. (#977)
- Watching an artifact page no longer keeps a Claude tab `waiting`, and a
  cancel ends the turn. (#868, #941)
- More of agy's dialogs turn its dot red: its MCP, file-access, wrapped
  question and expanded permission prompts. (#870, #990)
- `spyc -c` runs its commands in the order you give them. (#1031)
- A branch diff leaves out files that were changed and then put back. (#1046)
- Nine fixes inside archives: copies, renames, read-only mounts, and pane
  tabs, editors and tasks started from inside one. Checking a big archive for
  changes is much faster, since spyc now looks only at what changed. (#996,
  #1014, #1017, #1019, #1021, #1025, #1034, #1036, #1038; #1055, #1059,
  #1066, #1074)

## Under the hood

spyc's terminal engine is now pinned to libghostty-vt 1.0.0, its first
release with a stable ABI. (#1067)
