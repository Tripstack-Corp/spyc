## Heads-up

**Right-click opens a menu.** Right-click a file, a tab, the pane or a part
of the status bar to get a menu of what it can do, with each row's key
beside it. In Ghostty and Terminal.app a plain right-click on a file row now
opens that row's menu instead of the leader; right-click blank space for the
leader. In iTerm2, hold ⌃ as you right-click.
