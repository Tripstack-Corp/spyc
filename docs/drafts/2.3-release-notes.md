# spyc 2.3 — release notes

## The short version

2.3 is Projects: several repos open in one spyc, each with its own columns,
tabs and agents. Along the way agy, Google's Antigravity CLI, gets promoted to
a first-class agent. About 25 features, 40 fixes, and a lot less terminal-tab
Tetris.

## What's new

### Projects

One spyc now holds several projects, each with its own columns, pane tabs,
config and agents. (#99)

- `Space n` opens a directory as a project, `Space j` lists them to switch
  between, `Space x` closes one, and `Space Space` goes back to the last.
  (#751, #753, #759)
- `Space j` also lists the projects you closed lately, and reopens one with
  its tabs. (#803)
- `Space !` (`^a !` from the pane) takes you to the agent that needs you,
  whichever project it's in. The status bar shows each project's most urgent
  dot, and the window title counts the agents blocked in the others. (#780,
  #788, #790)
- Work you start in a project finishes there, even after you've moved on:
  file operations, archive writes, image and git views, the graveyard and the
  inventory. (#715, #717, #719, #841)
- `spyc -r` brings back every project. (#708, #765)
- Your own settings for a project go in `~/.config/spyc/projects/`, and
  `:project config` opens the file. (#794, #796)
- An agent's spyc tools act on its own project, not the one you happen to be
  looking at. (#706, #757)

### agy, promoted

agy now gets what Claude Code and Codex get.

- `^a v` pages its transcript, `^a g` shows the images you've given it, and
  `^a t` pages its thinking. (#830, #831, #848, #850)
- With `:agent hud` on, its strip shows its latest reasoning while it works.
  (#846)
- Its tool-approval and file-edit prompts turn the dot red, and `gf`, `J` and
  `^a u` skip its input box and dialogs. (#819, #832, #851)
- Its working dot stops when its turn does. agy redraws its spinner ten times
  a second while it works, so fifteen seconds of quiet means it's done,
  whatever its hooks say. And a cancel stays cancelled. (#853, #855)

### Smaller additions

- The `$` subshell has a bar across the top, so you know spyc is still there
  underneath. (#696)
- `[pager] scrollback_line_numbers` numbers the lines in `^a v`. (#820)
- Each plan window in the agent HUD says when it resets. (#690)

## Fixed: the greatest hits

About 40 fixes in all; `CHANGELOG.md` has every one. These are the ones you'd
have noticed.

- A typo in your `.spycrc.toml`, or a repo's that won't load, now costs you a
  warning instead of your whole config. (#826, #829)
- A repo's `.spycrc.toml` can't set your clipboard command. (#728)
- A worker that panics is reported and ends its own task, and leaves your
  terminal alone. (#837)
- A Codex or Claude Code idle dot no longer flickers back to working when the
  agent redraws. (#835)
- `^a v` shows a long Claude Code session from its start. (#804)
- The cursor stays on its file when the listing changes under it. (#813)
- `$` hands your terminal back the way it found it. (#710)
- `^a c` expands `%`, so `tail -f %` follows the file you're on. (#859)
- An agent waiting on another's merge keeps its spyc connection, however long
  the wait. (#857)

## What's next
