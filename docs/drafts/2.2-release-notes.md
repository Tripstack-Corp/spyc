# spyc 2.2 — release notes

## The short version

2.2 is mostly about running agents inside spyc, plus a new terminal engine for
the pane. About 40 features, 80 fixes, and one working dot that has been asked
to calm down.

## What's new

### A new terminal engine for the pane

The pane now runs libghostty-vt, the terminal core from Ghostty, in place of
vt100. Agents render the way they would in a real terminal. (#459, #465)

- Programs that redraw in bursts no longer flicker. brew's download list used
  to strobe; now it just downloads. (#591)
- Programs that ask the terminal what it supports get an answer, and it's the
  truth about the pane. (#594)
- Emoji in the pane take the width spyc budgets for them. (#485)

### Agent HUD

`:agent hud compact` puts a two-row strip under a Claude Code, Codex or agy
tab: model, session, context and usage. `:agent hud full` adds the tools the
agent leans on, each marked with its own failures. A Claude Code tab also
shows its todo list. It's off until you ask for it, because nobody likes a
dashboard they didn't order. (#656, #657, #660–#666, #674)

### Agents get set up once, not per project

spyc used to drop its MCP entry and status hooks into every project you opened.
Now it asks once per agent and puts them in that agent's own user
configuration; `spyc --install-agents` does the same from the command line.
Your repos are yours again, and the copies older spycs left behind get tidied
away. (#625–#634)

- spyc's MCP server only serves agents spyc launched, so two spycs in one
  directory each keep their own agents. (#509, #627)
- An agent knows which tab it's running in, so `get_spyc_context` can answer
  "where am I?" without guessing. (#507)

### Activity dots, now with more feelings

- A hollow `○` means an agent is waiting on background work that will wake it,
  like a CI run or a build. Not stuck, not done, just waiting for the kettle.
  (#651, #671)
- The working dot breathes in 16 eased steps, orange to gold. It used to start
  at pepper red, which looked a lot like an error. We were just too spicy.
  (#673, #685)
- `:why-status` explains what the active tab's dot is showing and why, and
  `:activity dump` now lists every MCP connection with the tab it belongs to.
  (#508, #609)

### `^a F` forks a conversation

Branch the active Claude Code or Codex conversation into a new tab and chase
the other idea without losing the first. agy can't branch a conversation, so it
says so instead of pretending. (#516)

### Startup tabs and prompt templates

- `[pane] tabs` in `~/.spycrc.toml` opens your usual tabs at launch. A
  project's own list opens only after you approve that exact list, because a
  repo you just cloned shouldn't get to start programs on your behalf. (#482,
  #494, #496)
- `[prompts]` saves the messages you keep typing. Bind one to a key or run
  `:prompt`, and spyc types it into the pane: pasted, never sent, so you still
  get the last word. (#517, #600)

### Agents you start from a shell tab

Start `claude` or `codex` by hand in a shell tab and spyc now notices, wires it
up like one it launched, and gives the tab back to the shell when the agent
exits. An `agent` key on `[[pane.tab]]` tells spyc what a wrapper script is
really running. (#612, #613, #616)

### Smaller additions

- Markdown in the pager folds by section, with vim's own keys: `za`, `zM`,
  `zR`, and `[[` / `]]` between headings. (#439)
- `J` offers the newest path the pane printed, which is usually the one you
  were about to type. (#529)
- `spyc -c <cmd>` runs a `:` command once spyc has started. (#534)
- `.spycrc.toml` binds any action by name, and `unmap` silences a key you keep
  hitting by accident. (#527)
- The status bar lists only the settings that differ from the defaults. Less to
  read, same information. (#521)
- Codex image attachments show up in the `^a g` gallery. (#617)

## Fixed: the greatest hits

About 80 fixes in all; `CHANGELOG.md` has every one. These are the ones you'd
have noticed.

- A restored session no longer deletes itself when it saves. Modesty is a
  virtue, but not in a session file. (#583)
- A Claude Code or agy tab is never saved with another tab's conversation.
  (#588, #607)
- Actions in column b no longer quietly operate on column a. (#502)
- A `remove_worktree` that fails partway can be run again to finish the job,
  instead of stranding the worktree. (#500)
- Jumping through a long list never leaves the cursor off the page. (#681)
- A drag-select now includes the cell it ended on. (#511)
- An emoji with a variation selector no longer shoves the rest of its row one
  column to the right. 🌶️ is one of those emoji, so this one was personal.
  (#503)
- A read-only file can be yanked again. (#515)
- Tab completes `.`, `..`, `~` and relative paths the way you typed them.
  (#644)
- Codex approval waits and questions are spotted through wrapping and redraws,
  and the dot recovers once you answer. (#548, #549, #560, #567, #672)

## What's next

2.3 is Projects. The plan is written and approved, and none of its code is in
2.2. Removing the old vt100 engine (#453) is the first change after the tag.
So long, vt100, and thanks for all the fish.
